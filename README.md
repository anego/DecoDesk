# DecoDesk

手持ちの画像フォルダから壁紙を自動生成し、定期的に貼り替える Windows 常駐アプリです。

タスクトレイに常駐し、指定したフォルダの画像をデータベースにインデックス化して、そこからランダムに選んだ画像を合成して壁紙に設定します。マルチモニターに対応し、各ディスプレイの解像度・配置に合わせて描画します。

## 主な機能

- **3種類の壁紙加工モード**
  - 加工なし — 画面の解像度に合わせて1枚の画像を配置します。
  - ポストカード風 — 白いフチとドロップシャドウを付け、ランダムな角度で傾けて複数枚を散らします。背景色は自由に指定できます。
  - コルクボード風 — コルクのテクスチャを背景に、プッシュピンで留めたように複数枚を配置します。
- **マルチモニター対応** — 各ディスプレイの解像度・配置座標・DPI を考慮して、1枚のスパン壁紙として生成します。
- **自動更新** — 10秒〜7日の範囲で更新間隔を指定できます。次回分の壁紙を事前に生成しておくため、切り替わりは瞬時です。
- **大量画像への対応** — SQLite によるインデックス管理と、バイナリヘッダからの高速なメタデータ抽出により、数十万枚規模のフォルダにも対応します。
- **フォルダの自動同期** — 対象フォルダへの画像の追加・削除を検知して、インデックスへ自動反映します。
- **Windows 起動時の自動実行** — 起動時に壁紙を更新する設定と、その遅延時間を指定できます。

## 動作要件

- Windows 10 または Windows 11（64-bit）
- **.NET ランタイムのインストールは不要です。** 配布物は自己完結型の単一実行ファイルです。

## インストール

1. [Releases](../../releases) から最新の zip をダウンロードします。
2. 任意のフォルダに展開します。インストーラーはありません。
3. `DecoDesk.exe` を実行します。

> 初回起動時、ネイティブライブラリの展開のため起動にやや時間がかかることがあります。2回目以降は通常の速度で起動します。

> ダウンロードした実行ファイルには署名がないため、SmartScreen の警告が表示される場合があります。その際は「詳細情報」→「実行」を選択してください。

## 使い方

起動してもウィンドウは表示されず、タスクトレイにアイコンが常駐します。

### タスクトレイメニュー（アイコンを右クリック）

| メニュー | 動作 |
| --- | --- |
| 今すぐ変更 | 壁紙を即座に更新します。 |
| 自動更新を一時停止 | 壁紙の自動更新を一時的に止めます。もう一度選ぶと再開します。 |
| 設定 | 設定画面を開きます（アイコンのダブルクリックでも開きます）。 |
| バージョン情報 | バージョンと実行環境を表示します。 |
| 終了 | アプリケーションを終了します。 |

### 初回セットアップ

1. タスクトレイアイコンを右クリックし、「設定」を開きます。
2. 「スキャン対象画像フォルダ」に、壁紙に使いたい画像のあるフォルダを追加します。複数登録できます。
3. **「インデックス更新」を実行します。** この処理で画像がデータベースに登録されます。完了するとタスクトレイに通知が表示されます。
4. 壁紙加工モードや更新間隔を設定し、「保存して適用」を押します。

> 対象フォルダや加工設定を変更して保存した場合、壁紙の再生成はバックグラウンドで実行されます。設定画面はすぐに閉じられ、完了時にタスクトレイへ通知が届きます。

### ゲームプレイ中の処理負荷を避ける

壁紙の生成は画像のデコードと合成を伴うため、実行中は CPU とディスクに負荷がかかります。ゲーム中にこの処理が走ると、フレームレートの低下や一瞬のラグの原因になります。

DecoDesk はこれを2つの仕組みで回避します。

**1. 全画面アプリの自動検出（自動）**

全画面で動作するアプリケーションを検出している間、自動更新をスキップします。操作は不要です。ゲームを終了すると次回の更新タイミングから自然に再開されます。

ただし、**ボーダーレスウィンドウで動作するゲームは検出できない場合があります。** その場合は次の手動停止を使用してください。

**2. 手動での一時停止**

タスクトレイメニューの「自動更新を一時停止」を選択すると、自動更新が止まります。実行中の壁紙生成処理もキャンセルされるため、停止直後に負荷が残りません。

停止中はタスクトレイのツールチップが「DecoDesk - 自動更新を一時停止中」になり、メニュー項目にチェックが付きます。もう一度選択すると再開します。

> 一時停止はアプリを再起動するとリセットされ、自動更新が有効な状態に戻ります。恒久的に自動更新を止めたい場合は、設定画面の「自動更新を有効にする」をオフにしてください。

> 一時停止中でも「今すぐ変更」は動作します。

### コマンドライン

壁紙を1回だけ更新して終了する One-shot モードがあります。タスクスケジューラなどから呼び出す用途を想定しています。

```
DecoDesk.exe --once
```

## データの保存場所

| 内容 | パス |
| --- | --- |
| 設定ファイル | `%LOCALAPPDATA%\DecoDesk\settings.json` |
| 画像インデックス DB | `%LOCALAPPDATA%\DecoDesk\decodesk.db` |
| 生成された壁紙・ログ | `%TEMP%\DecoDesk\` |

ログは日付単位で出力され、30日を過ぎたものは自動的に削除されます。

**元の画像ファイルが変更・削除されることはありません。** DecoDesk は画像を読み取るだけで、対象フォルダへの書き込みは一切行いません。

## アンインストール

1. タスクトレイメニューから「終了」を選択します。
2. 設定画面の「Windows 起動時に自動で実行する」を事前にオフにしておくと、レジストリの自動起動エントリが削除されます。オフにせず削除した場合は、`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` の `DecoDesk` エントリを手動で削除してください。
3. `DecoDesk.exe` を削除します。
4. 設定とデータベースを完全に消す場合は、`%LOCALAPPDATA%\DecoDesk\` と `%TEMP%\DecoDesk\` のフォルダを削除します。
