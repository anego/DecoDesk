# Database & I/O Rules (Phase 2 & 5)
- **テクノロジー**: `Microsoft.Data.Sqlite`
- **ファイル列挙の最適化**:
  - 大規模なディレクトリをスキャンするため、メモリを一括消費する `Directory.GetFiles` ではなく、遅延評価される `Directory.EnumerateFiles` を使用する。
- **高速メタデータ抽出**:
  - 画像ファイル全体をメモリに読み込まず、バイナリヘッダ（先頭の数バイト）のみをストリームで読み込んで幅（Width）と高さ（Height）を高速に解析するロジックを実装する。
- **SQLite高速化**:
  - データの挿入時は必ず明示的に「トランザクション（`SqliteTransaction`）」を開始し、バルクインサート（Bulk Insert）を行うことでI/Oボトルネックを防ぐ。
  - 画像のランダム取得クエリは、大規模データでも高速に動作するインデックス設計とSQLアプローチ（`ROWID` の活用など）を採用する。
- **同期処理**:
  - `FileSystemWatcher` によるリアルタイムのファイル変更検知は、バックグラウンドタスク（`Task.Run` や `Channel`）を介して非同期でSQLiteに反映する。
